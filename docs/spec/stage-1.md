# Stage 1 Scope

Stage 1 prepares a working internal dialogue/testing product slice: persistence contracts, health checks, admin visibility, RouterAI boundaries, deterministic business rules, knowledge/settings/audit surfaces, and acceptance scenario regression.

In scope:

- deterministic loan eligibility rules
- loan limits
- refusal reasons
- confirmed financial terms
- Web Test Channel dialogue ingestion
- RouterAI-powered structured extraction, image analysis boundary, and response generation
- Wazzup-ready architecture

Out of scope until later stages or confirmed data:

- Telegram production ingestion
- real Wazzup production traffic before official API contract verification
- business parameters marked `BLOCKED`
