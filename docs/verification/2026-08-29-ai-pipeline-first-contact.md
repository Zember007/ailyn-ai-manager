## Дополнительные полные Web Test сценарии

### S1-CAR-001 / S1-DLG-001 / S1-DLG-002 / S1-LIM-003

Шаг 1 клиента:

```text
Camry 2021, стоит 1500000 сом, нужно 500000 сом
```

Ответ содержит одно приветствие, предупреждение о регионе 10 и только следующий недостающий выбор программы. Факты в карточке: `Toyota / Camry / 2021 / 1500000 / 500000`.

Шаг 2 клиента:

```text
Без изъятия, Бишкек
```

Фактический ответ:

```text
Предварительно возможная сумма — до 600 000 сом. Окончательная сумма определяется после осмотра автомобиля и проверки документов. Пришлите, пожалуйста, фото лицевой стороны ID, обратной стороны ID, лицевой стороны свидетельства о регистрации ТС, обратной стороны свидетельства о регистрации ТС.
```

- `validation.passed = true`.
- Application перешла в `COLLECTING_DOCUMENTS`.
- Лимит соответствует `min(40% × 1 500 000, 600 000) = 600 000`.
- В ответ не попала служебная фраза rule engine.

## Важная граница проверки

Этот отчёт подтверждает реальные E2E-пути выше. Команда `pnpm test:scenarios` проходит, но текущий scenario runner содержит пять агрегированных contract-тестов и **не является** полным сквозным прогоном каждой строки acceptance-таблицы. Для заявления о полном покрытии всех ID нужен отдельный расширенный E2E harness; неотложенные интеграции STT, FX и праздничного календаря по согласованному scope остаются `BLOCKED`.
